最终设计方案

管理端前后端分离 + 专业UI重设计

技术方案

前后端分离
JSP仅作为入口壳页面加载HTML/CSS/JS，数据通过fetch调用JSON接口获取
纯CSS样式
不依赖Bootstrap，完全自定义样式，Tailwind风格设计系统
Chart.js图表
折线图展示趋势，环形图展示分布，轻量且API简洁
文件位置
HTML/CSS/JS放在 static/admin/ 下，浏览器可直接访问

目录结构

static/admin/
├── css/
├── variables.css /* 颜色、间距等设计变量 */
├── layout.css /* 侧边栏、顶栏、内容区 */
├── components.css /* 按钮、卡片、表格、表单 */
└── pages.css /* 页面特定样式 */
├── js/
├── api.js /* fetch封装，统一请求处理 */
├── router.js /* SPA路由（hash模式） */
├── components.js /* 侧边栏、表格、分页等组件 */
└── pages/
├── dashboard.js
├── users.js
├── guides.js
├── stories.js
├── destinations.js
└── comments.js
└── index.html /* SPA入口，只保留一个JSP壳 */
